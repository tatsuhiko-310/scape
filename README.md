# SCAPE — オリジナルボードゲーム試作

ルールを考えながら遊べる、すごろく型ボードのプロトタイプ。

## 遊び方

`index.html` をブラウザで開くだけ（ビルド不要）。

- **サイコロを振る**（またはスペースキー）で手番のコマが進む
- コマは**ドラッグ**で好きなマスへ動かせる
- **マスをクリック**すると名前・アイコン・色を編集できる（ブラウザに保存、JSON書き出し可）
- プレイヤー数 1〜4 人、サイコロ 1〜3 個

## 構成

| ファイル | 中身 |
|---|---|
| `js/config.js` | マス数・初期マス・色・プレイヤー、**ルールのフック (`RULES`)** |
| `js/dice.js` | 3D サイコロ |
| `js/main.js` | ボード描画・コマ移動・ターン進行 |
| `css/style.css` | 見た目 |

ルールが決まったら `config.js` の `RULES.onLand` / `RULES.onPassStart` に処理を書いていく。
