# SCAPE — オリジナルボードゲーム試作

ルールを考えながら遊べる、3D（アイソメトリック）すごろくボードのプロトタイプ。

## 遊び方

`index.html` をブラウザで開くだけ（ビルド不要）。

- **サイコロを振る**（またはスペースキー）で 3D サイコロが転がり、手番のコマが進む
- **Q / E** または右上のボタンで視点を 90° 回転、ホイールで拡大縮小
- コマは**ドラッグ**で好きなマスへ動かせる
- **マスをクリック**すると名前・アイコン・地形（草原/砂漠/水辺/溶岩/石畳）を編集できる（ブラウザに保存、JSON書き出し可）
- プレイヤー数 1〜4 人、サイコロ 1〜3 個

## 構成

| ファイル | 中身 |
|---|---|
| `js/config.js` | コース形状・地形・初期マス・建物・プレイヤー、**ルールのフック (`RULES`)** |
| `js/textures.js` | ドット絵風のマス／サイコロのテクスチャ |
| `js/main.js` | 3D シーン（Three.js）・コマ・サイコロ・ターン進行 |
| `vendor/three.min.js` | Three.js r160（MIT） |
| `css/style.css` | 見た目 |

ルールが決まったら `config.js` の `RULES.onLand` / `RULES.onPassStart` に処理を書いていく。

コースの形は `CONFIG.path`（向きと歩数の並び、合計30歩）を書き換えるだけで変えられる。
